# Proof that √2 is irrational

**Proof by contradiction.**

Suppose √2 is rational. Then √2 = p/q for some integers p, q with q ≠ 0 and gcd(p, q) = 1 (the fraction is in lowest terms).

Squaring: 2 = p²/q², so **p² = 2q²**.

Therefore p² is even, which means p is even (since odd² is odd). Write p = 2k.

Substituting: (2k)² = 2q², so 4k² = 2q², hence **q² = 2k²**.

Therefore q² is even, so q is even.

But now both p and q are even, contradicting gcd(p, q) = 1.

Therefore √2 is irrational. ∎
